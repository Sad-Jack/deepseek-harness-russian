# Проверка в установленном приложении

Дата: 3 ноября 2026, часовой пояс Europe/Moscow.

Приложение: DeepSeek Harness **0.2.1-rc.5**, macOS Apple silicon.
Пакет: `@local/dsh-locale-ru-021` **1.0.0**.

## Подтверждено через интерфейс

- Пакет установлен через **Plugins → Add plugin** из локальной папки. Первая предварительная проверка зависла; после обычного перезапуска установка прошла.
- После **Enable now** переключатель пакета включён; карточка показывает **1 всего · 1 работает**, компонент — **Работает**.
- Название, описание и оригинальный SVG-значок пакета отображаются в карточке и строке компонента. В английском интерфейсе до включения отображались английские название и описание.
- В **Настройки → Общие → Язык** появился **Русский**. Выбор явно сохранён через интерфейс; в настройке профиля подтверждено `locale.preference: ru`.
- После полного закрытия и повторного запуска интерфейс остаётся русским, плагин включён.
- Проверены основной экран существующей пустой сессии, боковая панель, общие настройки, раздел автоматизации без создания задач, список плагинов и карточка пакета.
- На странице плагинов отображается **Командная оболочка**, в карточке пакета статус **Работает** — исправления официального перевода загрузились.
- Версия приложения осталась **0.2.1-rc.5**. Архив приложения и его подпись не изменялись.

## Ограничения проверки и перевода

- Все 2 909 ключей проверены программно на реальном механизме локализации установленной сборки; все возможные экраны и ошибки вручную не воспроизводились.
- Системное меню macOS остаётся английским. Отдельные окна входа и обновления не входят в клиентский API языковых пакетов.
- Названия и описания некоторых экспериментальных плагинов остаются английскими: установленная версия читает их из собственных метаданных, а не из зарегистрированных словарей. Плагин эти метаданные не перезаписывает.
- Длинные русские подписи могут сокращаться в узких элементах существующей вёрстки. Вёрстка приложения не изменялась.
- Действия модели и платные API-вызовы для проверки не запускались. Переключатели разрешений, телеметрии и экспериментальных возможностей не менялись.

## Хранение пакета

Harness использует локальную ссылку на папку `dsh-locale-ru-0.2.1-rc.5` рядом с этим файлом. Сохраняйте эту папку на месте, пока плагин установлен. Архив `.tgz` — переносимая копия пакета для повторной установки.
